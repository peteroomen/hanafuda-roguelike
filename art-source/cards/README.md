# Traditional card faces

`wikimedia-traditional-black-border.zip` is the "SVG Hanafuda with traditional colors (black
border)" set from Wikimedia Commons:
https://commons.wikimedia.org/wiki/Category:SVG_Hanafuda_with_traditional_colors_(black_border)

The zip holds Commons' 1280×2099 WebP renders of those SVGs. September Kasu 1 came separately,
as `Hanafuda_September_Kasu_1_Alt.webp`. The game uses 320px copies in
`public/cards/traditional/<card id>.webp`. The black card back isn't used: it disappears on the
dark table, so both card styles share the drawn back.
